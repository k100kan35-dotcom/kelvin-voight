개념 설명

2D 격자 브러시 모델은 접촉 패치(Contact Patch)를 NxM 격자로 이산화합니다.

각 격자 셀에는 독립적인 Kelvin-Voigt 요소(스프링 + 대시팟 병렬)가 있습니다.

σᵢⱼ = E·εᵢⱼ + η·(dεᵢⱼ/dt)

• 격자 위치 (i,j)에 따라 하중 분포가 달라짐
• 롤링 모드: 접촉 패치 진입→변형 증가→이탈 시뮬레이션
• 상단 뷰: 격자 변형 크기를 색상으로 시각화
• 측면 뷰: 브리슬 변형을 곡선으로 시각화
